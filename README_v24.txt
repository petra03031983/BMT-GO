BMT GO v24 — заработок курьера и выплаты

Добавлено:
- экран «Мой заработок» для курьера;
- расчёт заработка по завершённым заказам (демо-модель: 80% стоимости заказа);
- суммы за сегодня, неделю и месяц;
- количество доставок за месяц;
- история выполненных доставок;
- запрос выплаты на карту/счёт;
- таблица courier_payouts и защищённая функция request_courier_payout.

Для Supabase:
1. Выполните supabase/v24_courier_earnings.sql после предыдущих SQL.
2. Реальную выплату на банковскую карту подключать через серверный платёжный/банковский сервис. Сейчас создаётся только защищённая заявка на выплату.
3. Перед продакшеном нужно отдельно учитывать уже выплаченные суммы, чтобы один и тот же заработок нельзя было запросить повторно.
