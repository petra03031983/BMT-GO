BMT GO v21 — LIVE TRACKING

Новая функция:
1. Клиент открывает заказ.
2. Если заказ уже назначен курьеру, приложение получает последнюю GPS-точку курьера из courier_locations.
3. Затем клиент подписывается на realtime-изменения courier_locations и двигает маркер курьера на карте.
4. Экран заказа показывает этапы: Поиск → Назначен → Забран → В пути → Готово.

Supabase:
- Выполните supabase/v21_live_tracking.sql после предыдущих SQL.
- Включите Realtime для таблицы courier_locations в Supabase.
- Убедитесь, что курьер действительно отправляет lat/lng в courier_locations.

Важно:
- Это реальное GPS-слежение только после подключения Supabase и разрешения геолокации.
- Файл не содержит секретных ключей.
