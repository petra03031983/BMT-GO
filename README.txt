BMT GO v18 — automatic nearest courier assignment

Что добавлено:
- заказ получает pickup_lat/pickup_lng, если у клиента доступна текущая геопозиция;
- после создания заказа приложение вызывает assign_nearest_courier;
- сервер ищет одобренного курьера с актуальным GPS (последние 2 минуты) в радиусе 15 км;
- выбирается ближайший по расстоянию;
- заказ атомарно получает courier_id и статус assigned;
- курьер видит назначенные ему заказы и свободные searching-заказы как резерв;
- если рядом нет курьера или GPS клиента отсутствует, заказ остаётся searching.

Установка:
1. Применить SQL из supabase/v18_nearest_courier.sql после SQL предыдущих версий.
2. Запустить Flutter с SUPABASE_URL и SUPABASE_ANON_KEY.
3. Для автоматического назначения у клиента должна быть разрешена геолокация.
4. Одобренный курьер должен включить GPS; его координаты считаются актуальными 2 минуты.

Важно: геокодирование адреса "Откуда/Куда" пока не подключено. Для точного маршрута следующим этапом нужны координаты обеих точек и маршрутный сервис.
