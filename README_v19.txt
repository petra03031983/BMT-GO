BMT GO v19 — точки доставки, расстояние и стоимость

Что добавлено:
- точка забора берётся из GPS телефона клиента;
- точку доставки можно выбрать прямо на Google Maps;
- рассчитывается расстояние по прямой между точками;
- ориентировочная цена: 1500 ₸ + 300 ₸ за каждый км (округление вверх);
- в заказ сохраняются dropoff_lat/dropoff_lng/distance_km;
- поиск ближайшего курьера из v18 сохраняется.

Важно: расстояние пока геометрическое, а не дорожное. Для точной цены по дорогам в следующей версии можно подключить Google Routes/Maps Directions API.

SQL: supabase/v19_delivery_points.sql

Для карты нужен Google Maps API key и обычная настройка Android/iOS Google Maps.
