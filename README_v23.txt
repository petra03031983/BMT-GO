BMT GO v23 — Рейтинг курьера и история

Добавлено:
- Клиент может один раз оценить курьера после статуса delivered.
- Оценка 1–5 звёзд + необязательный комментарий.
- Рейтинг и количество оценок хранятся у courier_profiles.
- order_ratings имеет RLS и серверную RPC submit_order_rating.
- История заказов сохраняется в orders; создано представление courier_order_history.

ВАЖНО:
1. Выполните supabase/v23_rating.sql в Supabase SQL Editor.
2. Не помещайте service_role key в мобильное приложение.
3. Реальный платёж из v22 по-прежнему требует webhook платёжного шлюза.
