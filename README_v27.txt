BMT GO v27 — Уведомления и realtime

Добавлено:
- in-app уведомления для клиента и курьера;
- индикатор непрочитанных уведомлений;
- realtime: новое уведомление появляется без перезапуска приложения;
- уведомления о создании заказа, назначении курьера и изменении статуса;
- уведомления о создании и обработке выплаты;
- админская обработка выплат из v25 сохранена;
- оплата картой из v26 сохранена.

SQL:

2. Применить supabase/v24_courier_earnings.sql.
